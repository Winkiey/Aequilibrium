## 新手路径

来信 → 逐句阅读 → 选择 → 看完所选后续 → 核对现金与约定 → 阅读报纸 → 老街 → 营业室 → 选公司 → 业务/营收/现金流/债务 → 填写预算 → 核对费用 → 明确确认 → 成交回单 → 找到持仓。阅读与走动不推进季度。

指引按六段展示当前目标。折叠按钮只收起说明，明确选择“自行探索”才结束教学；游玩说明可重新开启。关面板、返回标题、刷新或中途离开对话，保留分析步骤、公司与预算。旧档的显式跳过保持有效；实际已经买入时根据交易记录进入持仓核对。回看来信不倒退后来已完成的分析。

公司教学每页只聚焦一项信息，提供明确上一步和下一步。金额与费用确认前不会下单，确认后有重复提交保护。澄川能源只是资料阅读的入口，可选其他公司；不暗示稳赚。教学使用当前存档的真实游戏资金，允许停止教学、保留现金。

首次持仓核对直接显示已买入记录，不把点击持仓变成“去营业室再回账本”的循环。普通账本仍可前往所选公司的营业室资料。成交回单按当前教学/交易状态给出正确文字，卖出后不会误称刚买入。

## 剧情差异

新绘4张写实手绘原画，连同既有素材共37个场景背景：

- main-1 A：同一秋雨夜，展开的租约与钥匙，`bookshop-pledge`。
- main-1 B：同一雨夜，阁楼校样下收好的信，`attic-kept-letter`。
- main-2 A：冬夜为街坊准备的长桌，`reading-gathering`。
- main-2 B：上楼独自赶稿的阁楼，`proof-solitary`。

全部76个事件、152个后续有明确的关系与物件构图。站位不随说话人交换；来信/电话不生成站在房间里的远方人物，物件特写让开全身演员。物件根据文字采取递出、展开、留下、收回或挪开等有限动作，支持减少动态。A/B不默认对应温暖/冷淡或正确/错误。

新画已存在的租约、钥匙、信封、书与杯子不叠加重复贴片，查看圆圈跟随原画物件位置；顶部保留物件查看入口。选择界面不显示没有实际内容反馈的查看按钮。所有新增场景接入季节光线、窗景与桌面陈设，手机保持横屏。

完整新绘提示词/来源见 `ONBOARDING_ART_PROMPTS.json`；运行时使用带内容指纹的1440/960图像。慢请求15秒后可以重新载入，避免永久卡住。

这是构图与有限物件演出的改进，不是76个故事的完整角色动画。全部228套剧情组合仍复用固定人物与部分背景，不能把它们记作228张独立原画。
