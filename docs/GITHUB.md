# GitHub 发布准备

本项目已包含锁文件、开发说明、素材来源与 GitHub Actions。推送或创建 PR 时，CI 执行依赖安装、类型检查、31 项测试和生产构建。无需配置付费模型密钥，素材已在仓库内。

现有 `origin` 服务于当前私有 Sites，继续保留。将来提供 GitHub 地址后，可以添加单独的 `github` remote 并推送同一源码。当前尚未创建 GitHub 仓库或推送到 GitHub。

建议在发布前决定整体开源许可证，并填写作者与项目介绍。仓库公开与授予 MIT 等开放许可分别处理；本次没有代替作者指定许可。字体继续保留 OFL。AI 生成素材的制作方式、提示词与清单随代码提供，参考游戏的图像与音轨没有进入项目。

`.gitignore` 排除依赖、构建、环境文件、密钥、发布压缩包和本地工具状态。个人游戏导出存档、真实凭据与工作区研究截图不应提交。`.openai/hosting.json` 是当前 Sites 的项目绑定；复制为独立新站点时，应使用部署工具建立新身份。

本项目采用 Worker 构建，不能直接把整个仓库当作 GitHub Pages 静态站点发布。GitHub 可托管源码与 CI，当前可玩版本继续使用 Sites；若以后需要 GitHub Pages，应另行配置静态导出及相对资源路径。
