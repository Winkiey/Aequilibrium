# 雨夜来信 · 23秒片头

当前开场由雨中老街、校书工作间、程姨收书和信与钥匙四个动态镜头构成，接三秒片名。程姨去南方住一阵，信仍未拆；影片结束后进入原来的来信与选择。剧情、季度规则、结局及存档结构保持原样。最初64秒分镜方案保留为制作档案，不代表当前播放长度；十二个结局仍沿用各自的剧情演出。

四镜头由既有原创原画通过MiniMax H3生成，源片均为2560×1440、24fps。程姨保留年龄、脸型、发型和衣着；新表演包含低头看书、推书后抬眼微笑。老街视频增加本地制作的远近雨线、檐滴与地面水纹。原始视频与后期处理分别记录，未将旧图推拉短片登记为动态生成影片。

旁白为专门设计的原创成年女声，与十位剧情人物分开。Qwen3-TTS VoiceDesign与Base均使用本地已有模型，先生成参考，再以同一参考完成四句。未使用真人录音，未改变既有人物声线或264段人物对白。每句只有共同增益、边缘淡化和采样率转换，没有变调或加速；AAC单声道48kHz音轨随片头提供。

游戏影片没有压入字幕。播放器使用独立定时字幕、固定底部窄边，保留字幕开关；视频完整画面按统一比例置入2K画布，不裁切手、书、信和钥匙。字幕区与播放控制分开，手机横屏同样使用完整16:9画面。片头遵循人声音量及0%设置、总声音开关、减少动态、页面隐藏和竖屏暂停；浏览器限制有声自动播放时显示主动播放入口。

发布文件采用H.264/yuv420p、AAC与fast-start布局，保持2K，传输文件约12.6MiB。影片和封面使用内容指纹地址，放入约13.3MiB的独立可选影像包，更新游戏本体不必等它下载。在线直接播放，需要离线观看时再单独保存；已经缓存的旧版同一影片会在哈希核对后复用。原视频Range支持、逐文件SHA校验、更新备份与显式启用流程保留。缓存Range用Blob切片，HEAD和无效Range不读取完整影片体。
