# 人物与物件落点校正

2026-11-08。针对不同屏幕和镜头下的漂移，逐图目视审查现有37张背景及10组三姿态人物。

## 根因与修改

背景与热点此前经过原图cover裁切，人物和剧情物件却停在视口层；人物镜头还单独采用较小的缩放。现在实体人物、物件、季节静物都放入同一个原画世界，共用裁切、移动与镜头变换。界面对白和明确标出的“物件近看”保留在界面层。

`lib/game/composition.ts` 为37个地点分别记录开放地面的站位、人物高度、可放物件的工作面、已画物件与构图方式。高度以原图H计，不随说话者改变。同深度的两人保持接近的身高比例，车厢前后位置按纵深调整。真实分支地点传入解析器，避免用故事开场的房间决定后续站位。

三十个姿态按512×1024单格中alpha≥128的脚部位置校准，反向补偿换格时的横移与脚底留白。例如陆川第一、三姿态的脚部中心差约60px，不再通过交换人物站位或拉伸图像处理。原人物图、脸型、服饰与动作均保留。

坐标从原图左上计百分比，是美术落点，不是物理仿真或新增手持动画。物件主/副位置保持在各自支撑面，动作动画结束回到同一锚点，避免热点与物件分离。已画物件优先关注原画，灯/窗不作为漂浮的独立模型重复出现。

## 横屏与交互

热点的44px点击区域围绕圆心定位，文字标签另行放在旁边，不再因标签宽度偏移圆圈。移除手机样式中所有剧情物件被强制放到12%/43%的旧规则。超宽画面下，如果工作面被裁出画外，可从顶部“查看物件”打开近看。

季节静物固定在原图台面。裁切使静物不适合显示时隐藏该静物，保留季节光线、窗雾与落叶；不再为了保持可见而将它滑到地上或墙边。窗区也随原画逐处修正。

## 验证边界

自动检查覆盖原画配置完整性、三十姿态脚点、不同屏幕的比例换算、真实组件的物件/室外插入结构与现有全部剧情分支回归。原画联系表仅用于本地美术审查，非浏览器截图。此前Windows浏览器工具因无法可靠识别网址而停止，用户已取消整局试玩前提；本轮不绕过限制，也不将几何或静态渲染称为实际浏览器点击测试。
