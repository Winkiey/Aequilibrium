# 机制审计与改版基线

审计日期：2026-11-09。基线为提交 `b1d1545823d671dec22420a4b88138b3e213fb25`。本文区分已经存在的规则、实际验证结果与待实现的重构设计；不代表新规则已经发布。

## 当前机制的实际情况

### 书屋能否盈利

当前每季书屋经营净额为：

```text
-1400 + readers × 350 + catalog × 220 + [0, 800) 的种子波动
信用收紧时再减 600
```

接手后没有积累读者/目录时，每季必然亏损。读者和目录标记由部分主线、日常选项增加，此后每季重复加成；没有客流、购买转化、库存成本、定价、工资、书损与口碑留存的独立过程。当前屋顶是否完整修好，也不进入上述经营公式。

固定执行接手、办读书会、完整修缮、续租与期末维护的路线，运行种子1—1000；再增加一种策略：只在实际抽出的日常中优先选增加读者/目录的选项。日常与主线、续章一样在季初冻结，之后才答复，匹配 `CinematicGame.prepare()`；没有强行指定日常，也没有搜索最优解。完整路线、平局选择和已规范换行的源文件指纹见 [基线结果](MECHANICS_BASELINE.json)。

| 经营流水，十二季合计 | 无可选日常 | 日常优先读者/目录 |
| --- | ---: | ---: |
| 均值 | -¥9,452.63 | -¥6,868.84 |
| 中位数 | -¥9,350.33 | -¥7,037.93 |

审计修订：临时v1模拟在主线答复后抽取日常，得到6局为正、均值-¥6,854.65；该抽取时点与实际UI不一致。发布的v2脚本改为季初冻结，上表以v2为准。只修正实验方法，没有改变游戏规则。

这些只是 `shop` 类别的净经营流水，**没有再扣接手、活动投入、屋顶、续租保证金和末期维护**，不是总财富，也不是所有策略的获利概率。有些种子能在后期出现盈利季度，但该路线的三年整体回报仍然偏弱。

此外，接手费混合了押金与整理费，而当前净财富仅计算现金、股票、风险债权与借款，没有单列可退押金、书屋库存等资产。需要把“当季现金减少”和“发生不可回收损失”分开。

### 股价如何产生

开局生成一个种子，之后按“种子、季度、随机通道名”计算稳定的伪随机数。刷新页面、查看新闻、增加点击次数不会重新抽签。相同种子、相同规则能复现同一市场路径。

每季有36%的概率切到下一种市场状态，按复苏、扩张、热望、信用收紧循环。价格变动为以下各项相加后取指数，再限制单季幅度：

- 市场状态的基础项：1.2%、2.7%、3.8%、-5.5%（这是对数变化项，不是最终简单涨跌幅）。
- 公司独立噪声：约±7%。
- 9%触发概率的额外跳变，偏向负面。
- 隐藏估值与现价之比的缓慢回归。
- 通信、旧城两类公司的额外周期敏感项。

隐藏估值从开局股价出发，随宏观和另一项公司冲击变化。**公开营收、经营现金净额和具体负债水平没有直接进入估值或股价公式。** 两个序列有共同的宏观来源，但不足以构成“经营改善—估值改善—市场反应”的完整传导。

在审计用的合成反事实中，保持种子、周期、现价和隐藏估值相同，将六家公司营收扩大十倍、现金流设为严重负值、负债设为95%，下一季六个报价仍全部相同。该实验只修改隔离的模拟状态，不是可导入的正式存档。

### 新闻能否帮助判断

季报真实整理已披露的财务资料、报价变化和玩家约定，没有读取未来价格；这是已经实现的部分。但它主要解释已经发生的事，没有与未来经营和价格共享一个具体的订单、回款、融资事件模型。

若剧情固定写着扩建、回款放慢或报表不佳，市场模型不会因为这句剧情改变公司的后续经营。一些“付费核对账目”只增加 `verified` 标记、改变情绪，没有返回新的可行动证据。因此目前不能承诺玩家靠认真读报就能稳定改善投资决策。

### 玩家买卖是否改变行情

主动买卖改变现金、份额、成本、已实现盈亏、手续费、成交滑点、压力和当季交易次数，不修改公司报价、隐藏估值或未来随机数。1—1000种子，在相同主线与续章答复下，仅额外增加开局¥10,000澄川能源买入，十二季报价路径的差异为0。

这与普通小额投资者的身份相容。后续应保留“买入不操纵全市场”的边界，主要改善成交量、流动性与执行价格的联系。不能用玩家刚买入就必跌、刚卖出就必涨来制造难度。

### 剧情支出有没有未来作用

已有作用包括：读者/目录逐季增加经营净额；接手改变修屋顶的付款责任；借款会生成未来收款、改约与核销；局修会开放返修日常；选择改变关系、事件抽取条件和结局。并非所有选项只改变当前现金。

问题在于作用的强弱和可感知程度不一致：完整修缮不减少经营书损或停业；付费调查没有交付额外事实；疲劳没有形成工作容量限制；部分改变主要在结局阈值体现。相对的，即时收入非常清楚，长期价值往往难以验证。不能靠把代价隐藏起来制造犹豫，也不能把所有付钱选项都改成日后必赚钱。

## 改版目标：让玩家能够解释一笔得失

每个重要结果都应能追溯到可核对的链条：已经知道什么、当时作了什么选择、之后发生什么、哪一部分出乎意料。困难来自稀缺资源、估值和不确定性；认真观察应有用，结果仍有风险。

### 1. 共用的季度世界状态

公司、街区、书屋、报纸与人物消息共享同一份季度事件状态。先确定订单/回款/成本/融资等事实与待实现条件，再分别生成公开信息、公司经营结果和市场预期。随机通道按事件与用途隔离，查看资料和改变点击顺序不消耗市场随机流。

新闻标注“已确认事实 / 条件尚未落实 / 传闻 / 后续核验点”，保留消息日期和来源。披露是当时能知道的内容，不能泄露后来结果。公开好消息可以已被高估的价格消化；坏消息也可能已经被低估的价格反映。

### 2. 书屋形成可经营、可退出的业务

以少量有因果联系的状态替代永久固定加成：常客、库存结构、场所状况、可用人手、现金周转。计算到店与购买、售书毛利、活动费用、人工/房租/能耗和维护。订货先付款、售出才形成收入；滞销和应收占用现金。UI只展示可读的经营回单与下一步问题，不向玩家倾倒财务术语。

活动带来常客，也占用座位和人手；满负荷时继续办活动未必值得。修屋顶减少特定雨季损坏/停业风险；局修节省现金、保留部分风险。应同时存在经营转正、平稳小店、需要持续补贴的公共空间、及时退出等可达路径。经营转正不等于三年收回全部投入，押金与库存回收另算。

### 3. 经营事实进入公司估值，市场保留噪声

六家公司拥有不同的行业暴露、成本、回款周期和融资结构。经营结果决定可持续盈利/现金生成能力，结合债务与融资条件形成隐藏价值范围；报价围绕市场当前预期变化，并保留误判、预期修正和不可预知冲击。

玩家应能比较“公司经营怎样”和“现在价格已经要求多好的未来”。分红取决于实际盈利、现金和偿债条件；不再只按固定比例无条件派发。以除息处理和股东总回报对账，避免分红凭空增加财富。小额玩家买卖主要影响自己的成交结果，不能改变宏观周期。

### 4. 每个重要选项都有可以兑现的取舍

为每个分支登记：即时现金、占用时间、资金锁定期限、已知责任、会改变的经营状态、未来核验点和失败条件。关系回报可以是陪伴、信任与互助，不要求都换成金钱。

把“花钱 + 隐藏好人分 / 收钱 + 隐藏坏人分”改成两种可辩护的安排。例如免费读书会投入费用并占用营业时间，可能培养常客；付费包场带来合同收入，也要求保证场地时段并可能挤走常客。两者都可能适合特定经营状态。拒绝也可能是正确选择，不给所有拒绝统一惩罚。

重要后果在一到三季内通过实际账单、客流变化、履约记录或人物行动出现；期末总结指出因果，而不是只显示一句“你的选择产生了影响”。付费调查必须交付新的证据或减少一个具体未知条件；仍不保证投资获利。

### 5. 难度与验收

- 用同一批种子比较留现金、分散持有、随机交易、追涨、只用公开信息的判断策略；手续费、成交损耗和分红统一计入。先做多种子配对实验和结果分布，再调整系数。公开信息策略应带来可测的平均判断优势，不能靠读取隐藏价值；也不要求每个种子获利。
- 书屋分别验证低投入、读者经营、库存优化、过度扩张和退出策略。看经营利润、可用现金、回收投入和人的负担，不能只验收余额为正。
- 对每个重大选项在相同外部条件下做两条反事实轨迹，核对一至三季后的实际差异。若当前现金更差、未来现金更差、关系与可选行动也没有补偿，应重新设计或明确其赠与性质。
- 验证无无限循环套利、无刷新重抽、无免费分红造钱、无剧情写坏消息而公司实际完全相反、无“付费查资料却没拿到资料”。
- 新规则需要独立机制版本和明确迁移边界。旧价格、已发生账目、已答复剧情与既有付款不重算；先验证季末/季初迁移和完整旧档，再开放已有周目采用新规则。

建议实现顺序：共用季度状态与实验台 → 书屋闭环 → 公司经营/估值/新闻闭环 → 全部分支的实际后果与反馈 → 多策略平衡和旧档迁移。现有画面、人物和季度节奏可继续使用。

## 复现实验

```sh
node scripts/audit-mechanics.mjs 1000
```

脚本从当前 TypeScript 源码生成隔离模拟模块，不启动浏览器、不读取任何存档、不修改游戏参数；逐种子结果写入 `.sites-runtime/mechanics-audit/results.json`，汇总写入同目录 `summary.json`。发布基线保存汇总，不把生成模块与1000行原始轨迹加入发布资源。数值只代表本文注明的策略与版本，不能当作重构后规则的成绩。
