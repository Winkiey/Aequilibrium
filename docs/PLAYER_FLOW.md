# 阅读、决策与结局解释

## 阅读与收尾

剧情右上角可切换逐字或全句显示，偏好页也提供独立设置。全句显示不关闭场景演出、不跳过对白、不自动选择。旧偏好没有新字段时沿用原有显示方式；阅读事件、阶段、句子索引与声音全文身份不变。新周目保留用户选择的显示方式。

剧情区域与推进按钮支持空格/回车，输入、选择、重听与展开控件保留原生键盘行为。Escape可从工具按钮返回；暂停时不接收剧情推进。

已答复且读完的小事不再占据场景邀请，往事仍留在书柜；退出在途阅读可继续后续。本季续章由柜台承接，底部入口先打开本季安排，避免在同一场景重复发出续章邀请。结算与终章主行动放在纸页固定底部，不跟着长账目滚走。

## 决策与付费核验

选项原有事实分为眼前收支、到期安排、条件与责任，逐条保留金额、日期与不确定收款，不把押金重复相加。原始条款仍可展开。

公司核验先展示材料范围、无法证明的事项、费用与支付后现金，确认后调用原引擎收费。同一公司同季已取得的文件直接阅读。预览不读取未付费的合同状态，不使用未来股价或隐含基本面；剧情中的既有核验与费用保持原样。

## 通关后的解释

复盘增加可选展开的结局依据。结局名称始终取自现有engine.ending，不更改门槛、顺序或收益公式。所选结局可核对实际记录和原有条件；已经留下相关记录的生活方向显示未满足项与差距，严格大于/小于的边界保留。其他结局名称、未选剧情和收藏不会因此解锁。

这些数值是游戏记录，不是现实人物的情感量表。解释仅在通关后显示，正常剧情不出现关系分数条。

## 验证边界

三个独立提交分别执行类型检查、完整测试和Pages/Worker生产构建。已有测试保留，新增覆盖旧阅读游标、可选偏好、键盘焦点分工、在途后续、收尾行动、152个选项事实守恒、核验预览/收费与重复读取，以及十二条合法通关路线的结局解释。

本轮浏览器试玩仍受此前明确拒绝的来源权限限制；未换端口、浏览器或自动化绕过。静态渲染与引擎路线检查不作实机点击、手机布局或音频体验验收，也不生成伪界面截图。
