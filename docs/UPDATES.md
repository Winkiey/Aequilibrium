# 游戏更新与旧进度

## 已经开始游戏，怎样更新

在原来游玩的同一浏览器、同一用户配置中打开 **[游戏更新页](https://winkiey.github.io/Aequilibrium/update/)**，点击“保存进度并更新”。如果提示仍有游戏页面，请关闭其他标签页和已安装的游戏窗口，只保留更新页，再试一次。

更新页先备份本游戏的存档、阅读位置、偏好与收藏，再校验新版资源。完成后自动回到游戏，选择“继续这段日子”。无需清理站点数据，无需重新开始。浏览器、设备和用户配置之间的进度不共享；换设备请先从暂停菜单导出存档。

较早版本没有游戏更新入口，需要先用上述链接更新一次。之后标题和暂停菜单都有“更新 / 离线资源”入口；联网打开游戏或重新切回游戏时，会检查是否有新版，玩家选择保存后才切换。已完成的剧情和付款不会因更新重新执行，未选分支也不会因此解锁。

“检查本版完整性 / 修复缺失”负责修复正在使用的资源包；“检查游戏更新”负责查看新发布版本。两者用途不同。更新未完成时保留原存档与旧资源，联网后可以重试。离线时仍可继续已经准备完整的版本。

## 更新协议

- `/offline-manifest.json` 始终对应当前控制页面的 Service Worker，用于修复同一版本，避免旧入口混用新分包。
- `/release.json` 提供部署的最新清单；`/update/` 是独立静态入口，两者不加入离线资源清单。已发布的旧 Service Worker 会把这些陌生路径交给网络，新版也明确使用网络请求。
- 构建把 `buildId` 写入入口 HTML；游戏比较实际加载的构建与最新清单，不把“下载过新文件”当作“已切换版本”。清单与每个文件保留 SHA-256 和字节数，重复构建结果一致。
- 更新前只复制固定白名单中的本游戏存储键，不读取其他项目数据。备份采用 `aequilibrium.update-backup.v1`，原键不删除、不改名。备份写入失败会停止更新，提示先导出进度。
- 同项目、同资源组的旧缓存可复用，但每个文件都必须重新通过大小和 SHA-256 检验。新版完整标记仅在全部资源通过后写入；不删除旧版本缓存。
- 新 Service Worker 安装时不抢占正在游玩的页面。只有同源固定更新页、版本匹配、完整资源包和没有其他游戏页面的情况下，才允许显式激活。随后核对实际 active worker 的清单再返回游戏。

等待中的 Service Worker 与旧页面并存是浏览器生命周期的一部分。显式切换和多窗口检查用于避免旧页面配上新缓存的混合状态。参考 [Service Worker 生命周期](https://web.dev/articles/service-worker-lifecycle)、[MDN skipWaiting](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerGlobalScope/skipWaiting)、[MDN updateViaCache](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/updateViaCache)。

## 本次验证 · 2026-11-09

使用上一版真实静态产物，在相同地址先安装完整旧包，开始独立试玩，选择“暂时照看”，停在选择后的第 2/3 句。更换服务器产物后，普通刷新仍显示旧菜单；独立更新页成功识别新版本。

实际浏览器验证包括：多开一个旧游戏页时阻止切换；关闭后升级；重新打开的入口确实引用新版 JS；继续后准确接回第 2/3 句，再播最后一句并回书屋；现金仍为 ¥120,000、往事仍只有已选择的一条。停止预览服务器后，刷新、继续游戏、打开书柜均成功。重新检查显示“已是当前可用的最新版”。更新页在 844×390 和 667×375 横屏尺寸检查通过。

自动化检查覆盖旧清单仍固定、新发布入口可穿过旧缓存、切换来源/版本/完整性/多窗口限制、两个进度命名空间的原文备份、存储失败、跨版本校验复用与损坏文件修复。浏览器试玩使用独立进度，未改动正式进度。

## 下载与声音更新 · 2026-11-10

资源下载改为四路并发、媒体与入口安装重叠、图片分组传输、流式进度和自动重连。资源完整性与显式切换协议保持原有约束；原缓存保留。新清单增加可选 `bundles`，旧客户端仍可逐文件下载，更新页不会因该字段改变存档。

真实旧生产包在独立地址开始游玩，选择“暂时照看”，停在第二季第 2/8 句。普通刷新仍引用旧入口；明确更新后引用新版入口。前后两份实际导出的全部字段完全相同，现金 ¥121,000，阅读游标 `main-2/story/1`，两份均通过 validateSave。停止服务器后仍可刷新并继续同一句。手机横屏另验证暂停、恢复、完整标记及最终版本切换。详见 [本轮记录](DOWNLOAD_PERFORMANCE.md)。

四季配乐、场景天气与室内外音量变化随新版入口启用。已开局玩家沿用原进度，不需要重开；在暂停菜单开启“四季配乐与环境声”即可听到。
