# 手机横屏的经济读物

阅读册保持原有纸色、宋体、细线和十八章内容。桌面仍是左右对页；宽度不超过900px，或宽度不超过1200px且高度不超过600px的横屏，采用左侧书签栏与右侧单页。书柜分区、返回和收起入口保留。

书签栏显示卷名、当前章名、六卷目录，以及正文、例与图、概念辨析、原著札记四个直达入口。单页布局不再叠加“正文/札记”和札记标签两层横栏。正文、札记各自滚动，翻章固定在右侧页脚；切换札记类型回到新内容顶部，返回正文仍保留本章的阅读位置。章节改变时沿用原有的滚动复位。

目录在横屏下固定标题、搜索与合上按钮，只有卷目列表滚动。章节按原索引记录书签，资料、短引、概念练习与交互图完整保留。桌面翻页沿用立体书页，短屏使用轻微纸面掠光；减少动画时关闭。阅读分区的按钮不会触发全局左右键翻章。

适配集中在 `app/library.css`，移除了 `app/mobile.css` 中重复覆盖阅读册的旧规则。跨页面的安全区和外层书柜布局仍由原有手机样式负责，不能再在后加载文件中用同一组选择器重新压小字号和间距。

验证包含既有书签索引、全部章节内容与来源、十八章真实组件输出和四个直达入口的选中状态/回调/控制目标。保留原419项测试，新增两项交互与语义回归。静态输出、CSS构建和引擎测试不代表实机视觉验收；既有浏览器来源访问拒绝仍然有效，本次没有绕过或制作新的界面截图。
