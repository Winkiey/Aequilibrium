# 泊灯书屋：经营、投入与交接

书屋每天照常开门，不增加进货、排班滑块或频繁点收银的操作。玩家仍通过生活中的答复决定活动、修缮、轮值与去留，再在季末核对结果。

## 三种钱，分别记

- 首次接手支出18,000元：12,000元可退合约押金、6,000元不退整理费。押金计入净资产，不能用来买股或支付账单。
- 续租保证金总额15,000元，已有12,000元时，第十季只补3,000元；中途首次接手则需支付15,000元。
- 活动、整理、修缮和维护是费用。长桌、旧书整理、折扣、送书、延时照明与风扇等已有日常的已登记现金支出也纳入书屋费用；一次性售书收入单列。私人借出、垫款与回收仍在原往来约定中核对，不冒充营业额。

期满交接先以押金抵付书屋未付费用，再退现金余额；不直接抵私人借款。退回本金不算收入。选择继续经营时，押金继续作为资产保留，不在终局额外赠送一笔钱。

## 一季的经营怎样形成

经营单逐项列出售书、补货、房租、水电、整理照看和书损。经营初期留有交接时段；熟客活动、可用目录和经营积累会进入后续售书机会，季节与街区支出也会改变需求。

当前基础潜在售书额为9,300元，经营积累每季增加600元、至多四季；读者往来每级900元、目录每级650元，各至多三级。需求扰动、开门时间、季节和收紧周期作用后，再扣除漏雨导致的少卖。补货为实际售书的56%；每季房租1,500元、水电400元、整理照看800元；共同轮值后照看支出为500元。

营业利润＝实际售书收入−补货−房租−水电−照看−实际书损。临时停业少卖的部分已经减少销售，不会再扣一次。付不清的费用成为单列应付，不凭空消失，也不把未付支出藏成盈利。

经营单把当季结果冻结归档；翻到过去一季时，利润和原因属于那一季，累计净贡献、押金和待付款明确标为当前状态。阿棠会分三段说明结果，收支明细与条款可以展开。手机横屏将当季利润、累计净贡献和押金集中放在同一视图。

## 修缮的取舍

第五季完整修缮24,000元；改签局部修补9,000元。选择只记约定，实际付款验收后才改变屋面保护；当季营业在季末工程付款之前结算，因此保护从下一季开始。

局部修补后会收到余下工程的回访：15,000元余下工程加2,000元返场费，可以补完，也可以保留现金。这个即时补完分支在本季营业前完成，随后按完整屋面计算；保留局补时仍可能损失。相同天气下，局补将漏雨影响降至未修的45%；完整修缮去除这部分漏雨书损和停业影响，不消除市场需求风险。

修得完整可能更安稳，却未必在剩余租期内收回工程费。季度盈利与三年回本分别展示，不能将经营收入、押金退回或保留店铺混成投资回报。
