## 场景与对白

背景与人物、道具、季节装饰分别准备。只有真正显示并解码成功的全屏背景才能作为下一幕的交接底图。失败先自动重试；必要时使用清单中已有的另一尺寸，保持原有哈希校验。高 DPR 横屏优先选择 1440 图；不再先显示微缩模糊占位。解码缓存保留至多十二幅图像，预加载最多并行两项。此限制不包括浏览器原生 img 请求。视差使用合并到帧的 CSS 变量，避免每次鼠标移动重渲染整段演出。

打字中的已显示和未显示部分使用同一个文本流，完整句子的排版不会因为隐藏副本或光标宽度发生错位。切换说话者、台词或检查物件时重新绑定该句。返回与回看继续可用。

新周目的历史答复只显示小“曾选”，不进入剧情；只根据实际收藏且标签匹配的分支标记。没有按收藏顺序编造“上一次”。同一周目的前情为选择区一行辅助信息。有意义的人物回忆照常保留。旧存档保留开场快照和原始游标，只跳过可识别的旧机器提示。
