# 书柜阅读册 · 第二版

2026-11-08。发布目标：现有 [GitHub Pages游戏](https://winkiey.github.io/Aequilibrium/)。

## 阅读设计

阅读册使用暖灰纸、克制的书脊阴影、宋体正文、页边编号与细横线。将层级交给字号、行距和留白，避免堆叠圆角卡片、发光装饰和指标面板。没有新增图片或外部字体请求。

桌面左页读正文，右页有“例与图／概念辨析／原著札记”三种视角。六卷边签与可检索目录提供两条入口；章节末有相关章节。手机横屏采用单页“正文／札记”切换，保持可读字号，不把双页缩成小字。页内独立滚动，翻章回到页首。目录打开后聚焦检索框，支持Esc合上与键盘焦点返回，Tab在目录内循环；札记标签支持方向键、Home/End，翻章支持左右键。原有对开翻页动画继续保留；单页和减少动态偏好不执行三维翻页。

## 内容体系

六卷18章、36阅读页、17项相关阅读材料。每章包含三节正文、两个核心概念、一个辨析、一组关系图或交互图、一个原创生活例子、一道可展开思考题和关联章节。原著札记按核心问题、论证思路、阅读边界排版，区分教材、著作、论文、演讲与综述。两段原文短引仍以引号、斜体、译文及篇章定位区别于正文。

三组可交互图解使用独立编写的示意关系与数字：

- 价格：切换供给减少、需求增加，比较同样涨价下不同的成交量方向；静态基准点保留。
- 组合：切换两资产同向/反向变动，展示两种等可能情景的各资产与等权组合收益。
- 购买力：账户一年从100变为105，切换物价涨3%或8%，用比值式显示实际购买力变化。

资料细目、原始出处、核对日期及适用范围见 [READING_SOURCES.md](READING_SOURCES.md)。未复制书封、教材图表、实验材料或长段原文，未将拓展阅读冒充游戏引擎已经模拟的参数，也未泄露进行中故事的分支后果或隐藏评分。

## 存档与维护

原12章在 `READING_CHAPTERS` 内的索引固定，新6章追加。六卷顺序由 `READING_ORDER` 单独管理，旧 `readingPage` 仍指向同一章。自动书签保存章节，页内标签是临时阅读状态。76个事件的内部索引保持完整；更改目录不会改写剧情、交易、收藏或心理变量。

按用户持续授权，每次完成更新同步至现有GitHub主分支，等待Pages工作流完成，再核对公开网址。原Sites项目身份与访问范围保持。
