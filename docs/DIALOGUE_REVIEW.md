# 对话播放与季度季报复核

2026-11-09。

## 重复对白的原因与修复

原来每个选项的分镜后续，都会再追加`Option.response`。两者本来就在描述同一次答复，产生了人物说完、旁白再复述，甚至动作倒退的情况。雨夜暂不接手分支里，钥匙与“想清楚再说”就是这样出现了两次。

现在分镜是一份完整演出，存档中的答复摘要供人物簿、账本历史与复盘记录使用。播放时只选一份。已审核答复通过`outcome-responses.ts`的来源指纹关联分镜；旧档或条件变体的答复不匹配时，只播放它自己的文字，保留原金额、日期与说话者，不再硬接当前版本的演出。

两个开场分支调整为“明确答复—承接动作或回应—收尾”，钥匙和修后窗各只说一次。另修正了s06拒绝让人请客后的演出：原记录说她沉默，演出却让她开口；现改为主角的内心反应。

旧阅读游标也区分版本：已经读完旧演出、停在被移除摘要中的进度直接结束该段，不重新结算；新版本中途或末句继续保留位置。旧存档内容、收藏分支、开场版本和数值效果均不重写。

## 季报的信息与时间口径

入口和教学统一为“本季报纸”，刊名“澄港季报”；原“今晨/昨日”标签移除。

- 本季要闻：城市与市况、轮换的公司观察、与当前生活安排相关的街区消息。
- 六家公司：每家公司都有已披露营收、经营现金净额、负债水平、披露时点、与前一份记录的对照和不同的后续核对问题。首次资料与缺少历史的旧档不伪造增长趋势。
- 街区与约定：反映已有选择和过往往来；私人夹页整理本季/下季的已知付款与待收款，风险回款不作已到账处理。

只读取公开经营值和披露记录，不读取`fundamental`、`trueRevenue`、`trueCashflow`，也不预测未来价格。手机横屏保留三版入口、六家公司入口和核心三行财务数据；长解释在区域内滚动，切换公司从报道顶部开始。
