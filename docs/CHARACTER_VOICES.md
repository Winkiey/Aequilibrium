# 人物对白

十位原创人物使用固定合成声线，共 264 段、约 21 分钟，覆盖 76 个事件、152 条选择后续、12 段结局与银行招呼。相同人物、相同完整台词共用一段录音；条件变体和旧版已登记台词分别匹配。原文改变后不会误播旧录音。未登记的导入文本仍可正常阅读。

## 声音与阅读

点击开始或继续游戏时开启声音，随后对白随出场播放；本次已手动关闭的声音不会被开始按钮重新开启，设为零的音量继续保留。姓名旁可重听；快速切句会停止上一句，打字揭示不会重新播放。旁白、自述、报纸与资料保留阅读形式。暂停、关闭声音、离开画面或手机竖屏会停止或暂停人物声音；人物音量独立记忆，默认 70%，旧版两个音量及其 0% 值保留。人物开口时背景适度放轻，结束后恢复。

游戏复用一次点击开启的 Web Audio 输出，当前场景最多提前准备四段声音，预取串行且不阻塞新选中的对白。解码缓存最多十二段、24 MiB；切换画面不会重新下载已保存的同一文件。暂停恢复保留当前录音位置，重听从句首开始。

电话中的“远处的声音”经过轻微听筒处理：单声道、300 Hz 高通和 3,500 Hz 低通，两个滤镜线性 Q 均为 0.55，不加底噪、失真、回声或额外增益。浏览器的低通/高通 Q 参数按分贝输入，以 `20 × log10(0.55)` 换算，保持与离线试听相同的响应，参见 [Web Audio 规范](https://www.w3.org/TR/webaudio/#dom-biquadfilternode-q)。范围跟随分镜的 `channel: 'phone'`，仅有手机物件不会触发；来信、现场对白与银行招呼保留原声，往事回看沿用原场景标记。

滤镜在共享输出中实时连接原录音，不增加媒体请求、延时节点或另一份下载包；264 个原文件、内容地址和语音包版本保持不变。效果位于人物音量控制之前，暂停、结束、切句、离开和静音均断开本句滤镜，切回现场不会遗留电话效果。若同一录音的通话标记切换，按当前播放位置恢复。

语音失败不会阻止推进，按钮可重新取回声音；获取或解码超过七秒回到可重试状态，浏览器开启请求超过2.5秒也不会一直悬挂。收藏回看与结局使用同一份对白和音量设置。首次未缓存的文件仍受网络、浏览器与设备影响，不承诺所有手机零延迟。浏览器播放策略参考 [MDN](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay) 和 [Web Audio 最佳实践](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。

## 资源

开局四句随基础资源保存。完整对白 20,411,136 字节（约 19.5 MiB），作为独立可选包，逐文件核验大小和 SHA-256，可先于画面包单独保存。暂停保留完整文件，重开后继续核对与补齐；不承诺字节续传。声音文件名包含台词身份和内容指纹，不随界面更新重复下载。在线逐句缓存检查响应类型、大小与文件名中的内容指纹后写入同一个语音缓存，不创建整包完整标记；完整标记仍由整包逐文件核验后写入。即使当前页面尚无控制中的 Service Worker，播放器也会先读取已保存的对白。语音缓存不参与基础包完整标记，也不会阻塞游戏升级。

## 来源与验证

对白在本机 RTX 4060 上生成，游戏只播放预制 MP3，无需运行模型或提供服务密钥。使用 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) 的 Base / VoiceDesign 1.7B：Base 固定修订 `fd4b254389122332181a7c3db7f27e918eec64e3`，VoiceDesign 固定修订 `5ecdb67327fd37bb2e042aab12ff7391903235d3`。人物声音为原创合成参考；每人冻结一份参考，不借用真人、演员或名人的声音。

沈禾、阿棠沿用已选参考；程姨沿用 A 的声音身份。部分句子仅调整合成输入的标点以连接口语停顿，显示文字与所有字词保持一致。原始无损结果和备选保存在本地制作目录，不将模型权重或私有工作文件放进项目。

264 个 MP3 均独立解码检查；使用本地 faster-whisper-small、不提供目标台词提示进行转写，记录繁简与同音字差异，9 段重新生成后选择转写更准确的结果。详见 [逐句来源](VOICE_ASSETS.json) 与 [音频核验](VOICE_AUDIO_CHECK.json)。这些自动检查能发现明显漏读、重复和无效文件，不能代替对表演自然度的实际试听。

语音回归包括全文/说话者覆盖、旧条件变体、音频内容哈希、固定参考、暂停恢复、迟到播放承诺、快速切句、静音、失败重试、加载超时、可选包中断、跨版本复用及离线 Range 响应。剧情、经济数值和存档格式未因配音改变。

电话处理另有音频连接图、缓存复用与滤镜清理回归，所有开场和两条后续的真实组件输出均核对声音标记。同参数的程姨原声/电话音离线对照已经试听认可；自动检查与离线样片不代表手机或电脑浏览器的实机听觉验收。
