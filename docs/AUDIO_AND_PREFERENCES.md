# 声音播放与旅程偏好

## 进入与播放

开始、继续与重新开始的实际点击同步开启音频输出，再推进界面。页面加载本身不强制发声；本次手动关闭的声音不会被开始按钮重新开启，已保存的零音量继续保留。浏览器、手机竖屏和页面隐藏仍会停止声音，迟到的开启请求不能恢复旧对白。

人物录音使用整局共享的 Web Audio 上下文和有限解码缓存，场景之间保留已经准备的声音。当前场景按完整说话者与显示台词匹配，向前准备三句、加当前句最多四段；单次预取串行，当前句不排在预取队列后。缓存最多十二段、24 MiB，旧句被跳过后，下载结果只可作为缓存，不能再次播放。暂停保留录音位置，重听从头开始。

在线文件通过音频类型、大小与内容指纹检查后存入独立语音缓存，不创建“整包完成”标记。完整语音包仍按清单逐文件核验大小、完整 SHA-256 后标记完成，可单独保存，无需先下载画面包。原264段录音、人物参考、台词、剧情与存档格式均保持原样。

开启请求2.5秒无结果时可重试；文件获取或解码7秒未完成时停止本次播放等待。浏览器仍可能因为网络、设备性能或后台中断而等待，未将预取称为所有手机零延迟。参考 [MDN 自动播放指南](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)、[Web Audio 最佳实践](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。

## 开始菜单

保留“从那个雨夜开始”“继续这段日子”“翻开书柜”“第一次来到澄港”的文艺语气。技术性更新与下载入口并入“旅程与偏好”，有新版时只显示小标记。

## 本轮验证

TypeScript和383项测试通过。新增回归覆盖：共享输出、提前解码、热缓存复用、快速连点开启、跳过后迟到加载、暂停位置、静音、退出、隐藏/竖屏停止、浏览器开启挂起、解码超时、错误重试、缓存内存边界、没有控制中worker时的语音缓存读取、损坏缓存与错误内容拒绝；设置分类、完整操作回调及SSR安全也有检查。

这些是引擎与结构检查。浏览器权限检查拒绝了独立本地试玩页访问，本轮没有改用其他浏览器或自动化绕过，因此未完成真实手机、桌面播放延迟及视觉验收，也没有新界面截图或手机实测毫秒数。生产构建与发布状态记在交付检查点。
